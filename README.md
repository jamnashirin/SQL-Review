# SQL Review Project

##  Project Overview
This project contains SQL practice questions and solutions to improve my understanding of SQL queries and database management.

##  Objectives
- Practice SQL queries and commands.
- Retrieve and filter data from databases.
- Perform data aggregation and analysis.
- Improve problem-solving skills using SQL.

## Tools & Technologies
- SQL
- MySQL

## Topics Covered
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- Aggregate Functions (SUM, AVG, COUNT, MIN, MAX)
- Joins (INNER JOIN, LEFT JOIN, RIGHT JOIN)
- Subqueries
- CASE Statements
- Window Functions
